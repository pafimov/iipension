# Frontend

Дополняет корневой AGENTS.md.

- React + TypeScript strict. `app` собирает функции, `features/<name>` содержит UI функции, `shared/api` — общий клиент/сгенерированные типы, `shared/ui` — повторно используемые примитивы.
- Не создавать файл-комбайн. Компоненты разбивать по поведению; не вводить глобальный state-store без необходимости. Форма и расчёты не зависят от LLM.
- Серверные типы только из OpenAPI; не дублировать DTO и финансовые формулы. Денежные значения в запросах остаются строками.
- Семантический HTML, явные labels, клавиатурный фокус, error/empty/loading states. Не скрывать серверные ошибки и не стирать форму при неуспехе.
- Пользоваться общими CSS-токенами/примитивами, не вводить второй UI framework. Системные шрифты и локальные assets, без внешних CDN.
- Не использовать `any`, non-null assertions, `@ts-ignore`, HTML-инъекции, browser storage для сессии/финансовых данных.
- Мутации не ретраить автоматически. Блокировать повторное действие на время запроса. При новой странице с конкурирующими запросами учитывать размонтирование/устаревший ответ.
- Новые API-контракты сначала в backend и `make contract`. `make frontend-check`; для значимых сценариев `make e2e` на отдельном аккаунте.
- При изменении макета проверить 390px и 1280px, отсутствие горизонтального overflow, читаемость длинных значений, ошибки консоли, навигацию клавиатурой. Не считать сборку визуальной проверкой.
