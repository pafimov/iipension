# Происхождение и лицензирование

Исходный код этого каркаса написан для владельца проекта. Исходники других приложений и шаблонов не включены; публичные проекты в ADR служат сравнительными источниками. Зависимости устанавливаются менеджерами пакетов и сохраняют свои лицензии. Перед публичным распространением владелец выбирает лицензию собственного приложения и проверяет лицензии зависимостей. Приложенные продуктовые документы использованы как предоставленные владельцем требования; их нормализованные копии предназначены для команды проекта.
