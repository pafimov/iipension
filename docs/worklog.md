## 2026-11-21 · Интерфейс личной пенсии · FR-1 / US-1

Экран входа и форма используют белый фон и жёлтый акцент из референса. Форма начинается с желаемого дохода в месяц, затем идут сроки, накопления и риск. После сохранения и подтверждения фокус переходит к карточке плана. Суммы отображаются с разделителями тысяч и точными копейками, месяцы — словами. Финансовый прогноз пока недоступен. Схема API и миграции не менялись.

Пройдены `make check` и `make e2e` с локальным Django и одноразовой PostgreSQL 17. В Chromium при 1280 и 390 px проверены вход, блокировка отрицательного капитала, сохранение и подтверждение с клавиатуры, перезагрузка и выход. Просмотрены скриншоты, проверены длинные значения, отсутствие горизонтального переполнения и ошибок консоли.

## 2026-11-20 · Стартовый шаблон

Самостоятельный Python/Django + React/TS монорепозиторий. Вход по server session/CSRF, owner-scoped goal drafts/confirm, Decimal reference kernel, миграции, OpenAPI/types, проверки, контейнерный запуск и правила агентов. Нормализованы пять исходных продуктовых документов; незавершённые FR отделены от работающего каркаса.

Итог: make check пройден; 48 backend-тестов на SQLite и PostgreSQL, 3 frontend-теста, browser workflow через полный Compose/Nginx пройден на desktop/mobile. Миграции и health checks корректны; оба dependency audit без известных уязвимостей. Подробные результаты и ограничения — в docs/validation.md. Для локальной сети добавлена переносимая опция build-only CA, без сертификата в поставке/runtime. AI-провайдер, рыночные данные, полный расчёт и брокер не подключены. Внешний remote/деплой не создавался.

## 2026-11-21 · PostgreSQL в проверках CI

Переменные тестового PostgreSQL ограничены шагом `make check`. Это позволяет Compose использовать параметры из файла, созданного `make init-env`, для базы и миграций. С помощью `docker compose config` воспроизведено расхождение настроек до исправления и проверено их совпадение после него.
